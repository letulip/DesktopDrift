# Step 03 — itch.io page optimization

**Status:** page live, unoptimized · **Wave 1**
**When:** with Step 00 assets in hand; ~1 hour of edits. Ongoing: devlog + jams.
**Who:** owner (page settings) + promoter agent (copy, tags, devlog drafts).

## Goal

Turn the existing itch page from a parking spot into a converting page. itch's
own browse algorithm is weak, but the page is where every other channel lands —
and jams/devlogs are itch's real discovery mechanics.

## Checklist

1. **GIF cover** (Step 00, 630×500 ≤ 3 MB) — the single biggest change.
2. **Screenshots:** upload the 6 gameplay/UI picks from `docs/promo/screenshots/`
   (desktop + mobile mix; crop the `CROP-ME` file first).
3. **Tags** (itch allows ~10): racing, driving, drift, top-down, arcade,
   score-attack, singleplayer, pwa, browser, free. Genre: Racing. 
4. **Description rewrite** (promoter Workflow B): hook first ("drift micro-machines
   across the kitchen table"), controls, feature bullets from the fact sheet,
   devlog/YouTube link.
5. **Embed settings:** "Click to launch in fullscreen" + mobile-friendly flag ON
   (the game is touch-ready); viewport 1280×720.
6. **Metadata:** release status *In development* (honest + itch surfaces updates),
   platforms Web/HTML5, price $0 with optional donation ("pay what you want, $0
   minimum") — replaces the external donate link on this platform.
7. **Devlog posts:** each YouTube devlog episode gets a short itch devlog twin —
   every post bumps the game in followers' feeds and "recent" lists. Backfill the
   2–3 biggest past milestones (sound, reversed tracks, economy).
8. **Jams:** enter relevant web-game jams (racing/arcade themed or "playable in
   browser" jams) — jam entries get concentrated plays + ratings. Promoter scouts
   upcoming jams monthly.

## Gotchas

- Do NOT delist/redirect the GitHub Pages original — itch page and letulip.github.io
  coexist fine (only Poki would ever force that question — see Step 08).
- Keep the itch build/embed pointing at the same current version as GitHub Pages;
  update both on releases (add to the release checklist).

## Done when

All 8 items done; page views/CTR visibly move (itch analytics); devlog twin-posting
is part of the regular cadence in LOG.md.
