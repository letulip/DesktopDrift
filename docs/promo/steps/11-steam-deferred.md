# Step 11 — Steam (explicitly deferred)

**Status:** parked — revisit trigger below · **Wave 4+**
**Who:** owner decision when triggered.

## Why parked (decision record, so we stop re-litigating it)

- Needs a desktop wrapper (Tauri preferred over Electron for a 1.4 MB game),
  $100 app fee, real store-page marketing (wishlists decide launch visibility),
  achievements/cloud-save expectations, and a content bar ("free browser game
  in a wrapper" reviews badly without depth).
- The same effort invested in Waves 1–3 reaches strictly more players for a
  browser-native game right now.

## Revisit when ALL of these are true

1. Content depth shipped: tuning/car classes + ghost car + per-car records
   (ROADMAP Phase 2/2.5 remainder) — enough for a "full game" perception.
2. Some external traction proof: portal metrics or a devlog/Short that popped.
3. Owner has appetite for a proper launch campaign (wishlist build-up over
   ~2–3 months, launch-week attention).

## When triggered, the shape of the work

- Tauri wrapper repo (separate from this one), Steamworks SDK bridge for
  achievements (map the existing achievements table), offline saves already fine.
- Store page FIRST (screenshots/GIFs from the same capture kit), wishlist
  campaign via devlog/Shorts audience, THEN release date.
- Pricing decision: free vs $2.99-tier — with the web version staying free
  (Poki exclusivity, if ever signed, exempts Steam — see Step 08).

## Done when (for now)

Nothing to do. This doc exists so the question "what about Steam?" has a
written answer and a concrete trigger list.
