# Desktop Drift — наборы предметов для расстановки (вид сверху 2D)

Списки предметов под каждую из 6 локаций ([track_themes_proposal.md](track_themes_proposal.md)). Привязаны к реальным файлам в `DesktopDrift/items/` и `objects/`, чтобы можно было сразу найти и добавить, либо нарисовать новый по образцу.

## Условные обозначения
- ✅ **готов** — дескриптор есть в `js/items.js` + SVG на месте. Берём как есть.
- 🅰 **ассет** — SVG в репо есть, но дескриптора нет → дописать строку `{ hl, r, kind, imgSrc, c }` в `items.js`.
- ➕ **новый** — нарисовать SVG (вид **сверху**, портретная ориентация файла, масштаб 1:64) + дескриптор.
- **Коллайдер:** `○ r` — круг радиуса r; `▭ hl×r` — капсула (полудлина hl, радиус r). Значения в игровых единицах (как в `items.js`).

## ⚠️ Правило вида сверху (важно при подборе)
Мир — top-down. Предмет должен узнаваться **по плановому силуэту**:
- **Хорошо читаются:** всё плоское и вытянутое — тарелки/доски (круг/прямоугольник с кантами), приборы (нож/вилка/ложка), сковорода (круг + ручка = «капля»), телефон/книга/ноутбук (прямоугольник), инструменты (ключ, отвёртка, плоскогубцы — вытянутые с характерными концами), очки/наушники (две окружности + перемычка), ножницы (X), шестерёнка (круг с зубьями).
- **Плохо читаются** (сверху = безликий кружок, путается с тарелкой/чашкой): **стаканы, бокалы, бутылки, банки, солонки, чернильницы, горшки**. Их либо **не берём**, либо рисуем с отличающей деталью (ободок жидкости + точка-донце, крышка, носик, ручка-«ушки»), чтобы силуэт читался.
- **Высота** имитируется движком автоматически: `drawProp` рисует смещённую тень (offset 6,8) под предметом — рисовать сам предмет «плоско», тень добавит объём.
- **Коллайдер ≠ картинка:** физика — это капсула/круг (hl,r). У вытянутых предметов длинная ось капсулы = длинная ось силуэта (рендер сам поворачивает портретный SVG).

## Подсказки по расстановке (геймплей)
- **Крупные якоря** (тарелки, сковорода, ноутбук, доска) — в карманах/снаружи трассы; **мелкие/вытянутые** (приборы, инструменты, карандаши) — вдоль прямых, по касательной к направлению трека (как уже сделано в `track.js`: `ang` параллельно треку).
- **Не перекрывать гоночную линию:** держать `distance-to-centerline > TRACK_HALF + collider.r + запас`. Будущий **collision-validator** (ROADMAP Phase 3) проверит это автоматически — новые расстановки прогонять через него.
- **8–12 предметов на трассу** — как в текущем config1 (12). Смесь размеров для ритма.
- Угол вытянутых предметов задавать осознанно: `ang: 0` — длинная ось горизонтально, `ang: 1.57` — вертикально.
