## 🎮 ЧАСТЬ 1. Что заметит игрок *(в этот раз — «незаметное, но ощутимое»)*

### 1. 🏁 Честный Time Attack — чекпоинты по поворотам
Раньше чекпоинты могли кучковаться. Теперь они **смещены к апексам поворотов** и расставлены **равномерно по длине дуги**, а линия финиша **закреплена** с минимальным зазором.
- 💬 показать миникарту: точки сидят «по делу», в поворотах, а не пачкой на прямой.
- 💬 зачем: круг засчитывается честнее, трасса читается понятнее.
- Коммиты: `3ac89da` (апексы), `d3a91a2` (сектора по дуге), `cc1b61f` (якорь финиша + мин. зазор), доки `8ba50c7`.

### 2. 🛡 Античит очков — нельзя «фармить» комбо стоя на месте
Если дрифтуешь **в одной точке без продвижения по трассе** — рост множителя **замораживается** (через ~3 сек без прогресса).
- 💬 продемонстрировать: бесконечная «карусель» на месте больше не качает счёт; едешь по трассе — всё как обычно.
- 💬 это прямой ответ на находку ревью: «очки были эксплуатируемы».
- Коммиты: `f729686` (заморозка множителя без прогресса), `6b7306e` (якорь точки отсчёта в момент срабатывания).

### 3. 💾 Сейвы больше не обнуляются при обновлении
Раньше смена схемы сохранения = сброс к нулю. Теперь — **неразрушающая миграция**: данные накладываются поверх дефолтов + валидация содержимого.
- 💬 «обновил игру — рекорды, настройки и собранные крышки на месте». Для игрока это «ничего не пропало», и это важно.
- Коммиты: `399738d` (merge-over-defaults + миграции), `6633404` (валидация + реальная форма записи в тестах). PR #73.

### 4. 📴 Лучше оффлайн
PWA теперь честнее работает без сети: **fallback** при оффлайн-переходе (если открыли `game.html?track=…` офлайн — покажется оболочка, а не пустой экран), и **пропавшие CSS** (шапка/контент/футер) добавлены в кэш — больше не «голая» вёрстка офлайн.
- 💬 показать: режим «в самолёте» → игра всё равно открывается и выглядит правильно.
- Коммиты: `360a5b0` (CSS в precache), `e95f175` (оффлайн-навигация fallback). PR #72.

### 5. 🐞 Фикс: счётчик кругов больше не зависает
Лап-каунтер «замерзал» из-за пересоздания DOM-узла — поправлено.
- 💬 мелочь, но раздражала: `1/3` снова тикает как надо. Коммит `cdc9bbd`.

### 6. 🔧 Трасса Workbench — предметы убраны с гоночной линии
После правки SVG трассы инструменты налезали на трек; несколько проходов раздвинули их (дрель, наборы, расчёска) — больше **не «застреваешь» о предмет на линии**.
- 💬 «расстановка реквизита — это тоже геймдизайн: ничего не должно стоять на идеальной траектории».
- Коммиты: `50c260a`,`6d40c18`,`7dc2d15`,`a811929` (+ размеры предметов `f31bbed`, `e9ed625`).

## ⚡ ЧАСТЬ 2. Большой рефактор движка *(главная инженерная история недели)*

> 💬 Рамка: «Код-ревью сказало: вся логика заперта в одной огромной функции `startGame` — её нельзя протестировать и страшно трогать. На этой неделе я её разобрал.»

**Что сделал — за 7 шагов вынес «бог-функцию» в чистые модули:**
- `js/physics.js` — чистый шаг физики машины (`stepCar`).
- `js/collision.js` — стены, предметы, конусы, near-miss, пересечение финиша.
- `js/input.js` — обработка руля (`resolveSteer`).
- `nearestCenter` → `js/track-util.js`. Сам `game-engine.js` стал тонким **оркестратором**.
- Коммиты: `bb2aa01` (физика + golden-master), `ac8d047`→`555cf9e` (шаги 1–7). PR #69, #71.

**Ключевой приём — golden-master тест *(вот это интересно для зрителя)*:**
- Перед рефактором записал «эталонный прогон» (входы → выходы движка).
- После каждого шага сверял, что результат **бит-в-бит тот же**.
- 💬 мораль: «как безопасно резать большой модуль — фиксируешь поведение тестом-снимком, потом режешь по кусочку и постоянно сверяешься. Ноль регрессий».
- 💬 что получили: логику теперь можно тестировать по отдельности; добавлять механики — не страшно.

> 💬 Можно показать «было/стало»: один файл-монолит → оркестратор + physics/collision/input, каждый со своим тестом.

## 🏗 ЧАСТЬ 3. Под капотом *(коротко, для технической аудитории)*

- **Версия кэша теперь из хеша контента.** Сборка (`scripts/build.js`) вшивает SHA-1 минифицированных JS+CSS как `CACHE` → **больше не нужно руками бампать `vN`** (а забыть бамп = у игроков висит старая версия — это была реальная хрупкость). Коммит `e95f175`.
- **Сейвы:** неразрушающая эволюция схемы — миграции + валидация + тесты на реальную форму записи (`399738d`, `6633404`).
- **Инструмент проверки зазоров** `tools/check-item-clearance.js` — автоматически ловит предметы, налезающие на гоночную линию (то самое «на глаз» → автоматический guard, как и планировалось в роадмапе).
- **Чекпоинты по дуге/апексам** — `sampleCheckpointsByCorner` + `circularAdvance` в `track-util.js`, задокументированы (`8ba50c7`).
- **Правило verification-budget** (`25150dd`) — «не воюй с залипшим кэшем превью»: выстраданный урок из прошлой отладки, теперь записан как правило.
- **Док билд-пайплайна** (Terser→`dist`) в CLAUDE.md/AGENTS.md (`b9158a6`).
